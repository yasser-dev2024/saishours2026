# سايس الخيل — تطبيق Android

تطبيق Flutter عربي RTL لإدارة الخيول والإسطبل والمشتركين والاشتراكات والمالية دون اشتراط اتصال بالإنترنت أو مفتاح تفعيل. يبدأ كل تثبيت جديد بقاعدة SQLite فارغة خاصة بصاحب الجهاز، مع إمكان استعادة نسخة احتياطية بإرادته.

## المتطلبات

- Flutter Stable 3.32.4 وDart 3.8.1 أو إصدار متوافق.
- Android SDK 36 وJDK 21.
- جهاز Android 6.0 (API 23) أو أحدث.

## التشغيل والفحص

```powershell
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d DEVICE_ID
```

لا تمسح بيانات التطبيق أو تحذفه من جهاز يحتوي سجلات فعلية. استخدم التحديث فوق النسخة الموجودة وخذ نسخة احتياطية من الإعدادات أولًا.

## بناء Release موقّع

ملفات التوقيع الحقيقية محفوظة خارج المشروع، ولا توجد كلمات مرور داخل المستودع. نموذج المتغيرات موجود في `android/key.properties.example`.

على جهاز التطوير الحالي:

```powershell
.\scripts\build_release.ps1
```

الناتج:

`build/app/outputs/flutter-apk/app-release.apk`

نسخة التسليم المطابقة:

`release/HorseClub.apk`

للتثبيت كتحديث:

```powershell
adb -s DEVICE_ID install -r release\HorseClub.apk
```

## البيانات والخصوصية

- قاعدة البيانات المحلية في مجلد التطبيق، والمخطط يحافظ على 18 جدول أعمال.
- لا تُضمّن قاعدة الإصدار أي خيول أو مشتركين أو عقود أو تواقيع مسبقة.
- النسخ الاحتياطي والاستعادة يفحصان `PRAGMA integrity_check` والجداول الأساسية قبل الاستبدال.
- لا يوجد إرسال لبيانات الخيول أو الأعضاء إلى خادم.
- الأذونات التشغيلية هي الكاميرا لإضافة الصور والإشعارات للتنبيهات؛ يُطلب كل إذن عند الحاجة.
- جميع الصور المستوردة تُفحص من حيث الامتداد والمحتوى والحجم، ثم تُنسخ باسم عشوائي إلى مجلد التطبيق.

## أهم الوحدات

- الخيول: ملف كامل، صور، صحة، علاج، إيواء وغرف، تحذية، تمارين ومتابعة، مواعيد، مصروفات وخط زمني.
- الأعضاء: رقم عضوية، مميز/VIP، اشتراكات حالية ومؤرشفة، دفعات، سجل مالي، خيل وعقود.
- المالية: وارد ومصروف ودفعات إيواء وعلاج وسجل مركزي مترابط؛ دفعة الإيواء تظهر في ملف الخيل والمشترك بقيد واحد فقط.
- التقارير: 20 تقريرًا عامًا، إضافة إلى ملف عضو شامل وملف خيل شامل أسبوعي أو شهري أو كامل مع الصور.
- التنبيهات: جرس نابض بعدّاد، مركز تصفية، وإشعارات Android وصوت jrs افتراضي دون مفتاح تفعيل داخل التطبيق.
- الإعدادات: اسم النادي والأسعار والخدمات والعقد والشعار والتوقيع والختم والنسخ والاستعادة.
