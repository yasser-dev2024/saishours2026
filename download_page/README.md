# صفحة تنزيل سايس الخيل

صفحة عربية ثابتة لا تجمع بيانات الزوار ولا تستخدم أدوات تتبع أو مكتبات خارجية. زر التنزيل يشير إلى أصل الإصدار الرسمي في GitHub Releases، وبصمته في `downloads/HorseClub.apk.sha256`.

الملف المنشور هو الإصدار الكامل نفسه المستخدم على الجهاز، ويشمل جميع أقسام الخيول والمشتركين والاشتراكات والحجوزات والرعاية والمالية والتنبيهات والتقارير والنسخ الاحتياطي والكاميرا، دون نسخة مخففة منفصلة للويب.

## النشر اليدوي على Netlify

1. افتح لوحة Netlify واختر **Add new site** ثم **Deploy manually**.
2. اسحب مجلد `download_page` كاملًا إلى منطقة الرفع؛ لا ترفع ملف `index.html` منفردًا.
3. بعد اكتمال النشر افتح رابط الموقع عبر HTTPS واضغط زر التحميل مرة واحدة للتحقق.
4. تأكد أن الزر ينزّل `HorseClub.apk` من GitHub Releases وأن نوعه `application/vnd.android.package-archive`.
5. قارن SHA-256 للملف المنشور بالقيمة التالية:

   `179681E673BE66434EE666821211D0E0210FAB200FD6D44E8D5C8FF347DD46F8`

إعدادات الأمان ونوع ملف APK مضبوطة في `netlify.toml`، كما يوجد ملف `_headers` للتوافق. لا يلزم بناء JavaScript أو تثبيت حزم.

## النشر على GitHub Pages

يبقى `index.html` في مساره الحالي داخل `download_page`. سير العمل الموجود في `.github/workflows/deploy-pages.yml` يرفع **محتويات المجلد** إلى جذر GitHub Pages تلقائيًا عند تحديث فرع `main`؛ لذلك لا حاجة إلى نقله إلى جذر المشروع أو إلى مجلد `docs`.

الرابط المنشور لهذا المستودع:

https://yasser-dev2024.github.io/saishours2026/

استخدام GitHub Releases لملف APK يضيف اسم ملف تنزيل واضحًا ويتجنب الاعتماد على استضافة Pages للملفات الثنائية الكبيرة.
