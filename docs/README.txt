صفحة تحميل إدارة نادي الخيل
============================

هذه الصفحة مستقلة ومهيأة للنشر من مجلد /docs في GitHub Pages.
زر التحميل يشير نسبيًا إلى:

./downloads/HorseClub.apk

لا تُعدّل بيانات الإصدار والحجم والتاريخ والهاش يدويًا.
شغّل build_android_and_web.ps1 من جذر مشروع Flutter ليُعاد بناء APK
وتحديث الصفحة تلقائيًا.

يجب رفع docs/downloads/HorseClub.apk مع الصفحة، ولا يجوز استبداله بصفحة HTML
أو رابط file:/// أو مسار محلي من الكمبيوتر.
